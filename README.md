## Апекс - точка касания эллипса , который вписан в прямоугольник (коробку)
## Точка большой полуоси - есть конец максимального радиуса эллипса 
## Мы используем только направление вектора курсора для смещения апекса, а площадь всегда держим максимальным , за счёт рассчета максимально возможного радиуса и максимального допустимого соотношения их
## Эллипс не выходит за рамки "коробки", не сужается при максимальной диагонали.
